# Rainha Costela Menu

Crie um cardápio digital responsivo para Rainha da Costela, priorizando smartphones (Mobile First).

Design: identidade rústica premium, elegante e profissional, com tons de marrom, madeira, preto e dourado. Utilize a logo enviada como referência. Evite aparência de template genérico ou vibe coding.

Conteúdo: utilize todos os produtos, categorias, descrições e preços do PDF enviado, sem alterar informações.

Apresentação:

Cabeçalho com logo, nome e slogan "O simples que encanta".

Navegação horizontal entre categorias.

Produtos organizados em listas elegantes.

Nomes, descrições e preços bem destacados.

Endereço: Rua Barros Barreto, 376 • Santo Amaro – PE.

Restrições: não utilizar fotos, imagens ilustrativas ou emojis decorativos. Não criar carrinho, pedidos, pagamentos, WhatsApp, login ou painel administrativo.

Objetivo: criar uma vitrine digital sofisticada, leve e intuitiva, exclusivamente para consulta do cardápio, com excelente experiência em celulares.

Implemente diretamente a página completa, com código organizado e responsividade, sem criar funcionalidades desnecessárias.
